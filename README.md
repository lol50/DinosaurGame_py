# Dinosaur Game

Бесконечный раннер на Python. Управляй динозавром, уклоняйся от кактусов и птиц, бей рекорды.

<p align="center">
  <img src="https://github.com/lol50/DinosaurGame_py/main/assets/dinogif.gif">
</p>

## Управление

1. Прыжок динозавра - клавиша Пробел или Стрелка вверх
2. Пригибание динозавра - клавиша Стрелка вниз
3. Включение паузы - кнопка паузы или клавиша Escape
4. Отключение паузы - кнопка "Продолжить" или повторное нажатие на клавишу Escape
5. Перезапуск игры - кнопка "Перезапуск" или клавиша Пробел

## Установка

1. Для начала скопируйте репозиторий используя команду:

```
git clone https://github.com/lol50/DinosaurGame_py.git
```
**ИЛИ** скачайте Zip-архив и распакуйте его содержимое.

2. Затем загрузите необходимые зависимости в командной строке или терминале, используя следующую команду:

```
pip install -r requirements.txt
```

# Запуск
3. После установки просто запустите команду:

```
python main.py
```
# Сборка EXE файла

1. Для начала надо ввести комманду для установки:

```
pip install pyinstaller
```

2. Затем упаковать все в exe файл:

```
pyinstaller --windowed --name DinosaurGame --add-data "assets;assets" main.py
```
**Убедитесь что exe файл и assets находятся в одной папке!**
